# Effective semantic execution trace — sole public format

## Versions and boundary

The sole active model-visible wire contracts are
**`semantic-execution/3`**, **`semantic-trace/3`** and
**`semantic-context/3`**. Private supervision/certificates are
`semantic-supervision/2`; committed-state packets use
`semantic-continuation/3`. The raw owned interpreter journal and source-language
profile have **separate versions**. Production does not parse, generate or
serve an earlier public trace format. Historical version-two material is a
pinned comparison artifact, never silently relabeled or interpreted as v3.

The training target describes *what was computed*, not a lossless listing of
interpreter instructions. Read provenance, intermediate VM stack state,
shape versions, private arrivals and raw journal IDs are not model predictions.
Only observed context and previously committed generated bytes can condition
future decisions. A failed witness computation is reported, **never repaired
from the reference**.

## Public record grammar

Every logical record is `kind {canonical JSON fields}`. The sole codec lives
in `src/training/format.js` and rejects unknown/missing fields, uncanonical
scalars and incorrect fragment framing. Public fields and operations:

| Record | Committed semantic meaning |
| --- | --- |
| `code` (observed) | Full source text, entry and complete static source-site inventory, plus an explicit seed when relevant |
| `input` (observed) | Initial data graph: identities, aliases/cycles, holes, null-prototype objects and special scalar tags |
| `compute` | Bounded typed primitive expression and claimed result, including deterministic seeded RNG |
| `choose` | Evaluated value and selected `then`/`else` or short-circuit branch |
| `bind` | Live cell write or checked copy of an existing iteration cell |
| `allocate` | Ordinary array/object, closure with captured cell identities, or bounded owned internal collection identity |
| `read` / `write` | Presence, value and mutation of a committed location |
| `call` | Dynamic invocation and explicit receiver/arguments |
| `transfer` | Pending return/throw redirected through cleanup or handler |
| `return` / `throw` | Actual completion of an invocation |
| `request` | Active invocation ID, exact JS call expression span, evaluated tagged arguments and canonical immutable JSON payload; consumed against ordered authorized fixtures |
| `observe` (observed) | Result supplied by an authorized committed external effect |
| `job` | Bounded owned FIFO enqueue/dispatch/complete |
| `end` | Terminal root completion after required work is resolved |
| `value-open`, `value-part`, `value-close` | **Transport only**; fragments do not represent guest calculations |

The primitive-expression grammar permits at most eight operators and 32 nodes.
Each record must fit the configured physical budget or be split by deterministic
transport framing; fragments are not new computation steps. The visible
source-site dictionary is computed *before* knowing which branches execute.

## Observable and correctness contracts

The bounded data boundary retains enumerable configurable writable data slots,
array length, absent indices versus present undefined, aliases, cycles and
null prototypes. It refuses unmodeled descriptors, exotic prototypes, proxy
boundaries and rich return objects instead of flattening them through getters.
An internal Set/RegExp identity is not license to serialize that object as an
ordinary data graph.

Three checks remain independent:

1. **Task correctness** compares selected terminal completion, reachable data
   graph and permitted effect observations against independently obtained
   reference facts. Different correct decompositions or identity spellings
   need not match teacher text.
2. **Witness consistency** checks each explicit claim against previously
   committed public values. An incorrect intermediate computation can coexist
   with an accidentally correct final result; neither is silently rewritten.
3. **Artifact integrity** independently replays the private source execution,
   verifies compaction certificates and reruns reference comparisons on the
   serialized demonstration. Locally verified does not imply independent
   megatoken corpus admission.

External requests are checked against the same static Acorn site inventory and
`canonical-json/1` host argument codec used by the owned runtime. Requests
whose operation, source callsite, active invocation, current argument graph or
immutable payload disagree are rejected before fixture consumption. This is
selected-state consistency, not independent proof that an effectful JS program
executed correctly: the effectful training compiler remains fail-closed.

The selected controller lives in `src/training/controller.js`; only that
controller, plus `src/training/rollout.js`, determines selected-state validity.
`src/training/causal-audit.js` verifies public visibility without reading the
private final state. The human renderer consumes committed public records and
does not replace the raw model target.

## Capability limits and admission

The current exporter certifies a bounded subset of source execution: pure
scalars, branches/loops, aliased data mutations, nested direct calls, captured
cells, ordinary data collections and supported caught/finally paths. The
standalone controller has typed effect and job operations, but the **teacher
compiler and corpus gate do not yet certify all external, accessor/coercion
callback, promise/await/reaction and rollover paths**. Unsupported cases are
refused with evidence, not admitted by presence of a wire record. No learning
gain has been measured from merely shortening source traces.

The paired `werg/megatoken` converter preserves the exact UTF-8 physical
records, native recurrence, visibility ownership and generation loss. The
byte-fallback codec is diagnostic. The required actual model-selected
three-seed comparisons remain separate from parser and oracle smoke tests.
