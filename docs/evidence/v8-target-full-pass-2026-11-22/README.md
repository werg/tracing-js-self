## Remaining scope and lessons

This result qualifies the exact original pair and contract above. Any later
expanded contract or paired executable revision requires its own full target
campaign. The later explicitly selected full-coverage driver is a separate change;
its bounded default route must not be credited with the complete pass documented
here. The distinct local retained-input run used torch 2.14.1 and older input-policy
pins and has its own evidence directory.

Token/mask-position coverage remains **unmeasured**; learned behavioral success
remains **null**. The service route exercised original failed/unacknowledged
selections and exact continuation, with zero acknowledged semantic selections;
accepted-record recovery is not established by this run. Production launch, its
larger model/assets, GPU fit and throughput are separate gates.

The actual full pass resolves both failures in the earlier attempts: identifying
programs by their canonical source annotation rather than their shared adapter
name, and handling observation-only steps without loss plans. Complete immutable
admission reuse and final-step checkpointing made the full measured budget
practical without changing the target objective. Independently enumerating the
prepared policy-target universe prevents the planner and optimizer from silently
agreeing on the same omitted target.
