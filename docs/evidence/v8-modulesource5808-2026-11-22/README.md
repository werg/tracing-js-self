## Lessons and remaining work

This exact pair still imports the shared hash via the legacy
`algorithm_v7` module. Subsequent combined optimizer-resume testing identified
that dependency as incompatible with the existing legacy-wire import boundary.
The correction imports the same hash from neutral `semantic_json`; that
later candidate has its own qualification and must not inherit this run's
identity.

The example establishes physical packing within the existing limit, despite
large complete contexts. Its source artifact is already 29.5 MB, close to the
unchanged 32 MiB producer recheck input cap, and it retains about 308 observation
tokens per supervised position. Production cost, broad module-family coverage,
additional module graphs, cycle and namespace composition, and learned model
execution remain open. Default module data admission remains refused unless
the caller explicitly requests the bounded scheduler source profile.
