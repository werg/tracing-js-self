## Retention and reproduction

`qualification-index.json` checksums every compact receipt and every private
compressed per-case artifact. The latter retain graph-encoded tasks, full
results, and fresh rechecks outside Git. Run the documented
`tools/check-real-source-cases.mjs` with exact IDs and the pinned native paths
to produce a new immutable qualification directory. Historical artifacts are
never overwritten. No optimizer steps or learned-success claims are made here.
