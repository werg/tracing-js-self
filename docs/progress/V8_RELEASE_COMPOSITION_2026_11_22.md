## Lessons and next gate

A model checkpoint deliberately declares verified model reexecution: restoration must preserve consumed attempts and pay reconstruction costs, while prohibiting repeated external effects. Zero historical decoder activity is the wrong positive recovery contract; it remains correct for pre-authority refusals.

The original preparation artifact and its admitted copy are different documents. The actual prepared receipt binds the original source document. Registration order and dataset order may also differ while complete membership is equal. The new release code preserves the original artifacts, verifies full membership/splits, and replays preparation in the stored episode order rather than rewriting the dataset.

Every qualification remains bound to its measured source, runtime and population. The current composition must retain all existing main evidence and unique controls, explicitly reconcile policy/source overlaps, pass the complete recovery gate, resolve any concrete source/artifact correspondence defect, then run the real two-update package/restore gate. Runtime package versions are checked; installed wheel/file hashes and a hermetic container image are not independently attested. Learned quality, production parity, full-language support, edition applicability, dynamic descendants and unknown external outcomes remain separate open requirements.
